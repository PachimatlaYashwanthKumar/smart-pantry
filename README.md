# 🥫 Smart Pantry

A full-stack MERN application for managing household groceries and pantry inventory. The platform helps users organize food items, monitor stock levels, track expiry dates, manage shopping lists, record expenses, and gain insights through analytics.

## ✨ Features (Planned)

- 📦 Pantry inventory management
- 🛒 Smart shopping lists
- ⏰ Expiry date tracking and reminders
- 💰 Grocery expense tracking
- 📊 Dashboard with analytics
- 🍽️ Recipe suggestions based on available ingredients
- 🔍 Search and filtering
- 🔐 Secure user authentication
- 📱 Responsive design

## 🛠️ Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js
- TypeScript
- MongoDB
- Mongoose
